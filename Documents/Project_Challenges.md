# Project Challenges

Throughout the project, several data quality and technical challenges were encountered.

## Challenges

### Duplicate Employee Records

The dataset contained ten duplicate employee records which required identification and removal before analysis.

---

### Missing Values

The YearsWithCurrManager column contained missing values that required assessment before determining their impact on reporting.

---

### Inconsistent Categories

The BusinessTravel field contained inconsistent naming conventions that affected grouping and visualization.

---

### CSV File Limitation

Initial analysis was performed on a CSV file. Since CSV files cannot retain multiple worksheets, formulas, or formatting, the dataset was converted to Excel Workbook format before continuing the project.

---

### Dashboard Design

Designing an executive-friendly dashboard required balancing visual appeal with readability while maintaining accessibility for users, including those with color vision deficiencies.
