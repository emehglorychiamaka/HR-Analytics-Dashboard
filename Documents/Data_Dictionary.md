# Data Dictionary

| Column | Description |
|---------|-------------|
| EmpID | Unique employee identifier |
| Age | Employee age |
| AgeGroup | Employee age category |
| Attrition | Indicates whether an employee left the company |
| BusinessTravel | Employee travel frequency |
| Department | Department where employee works |
| Education | Education level |
| EducationField | Field of study |
| Gender | Employee gender |
| JobRole | Employee job title |
| JobLevel | Employee level within the organization |
| JobSatisfaction | Job satisfaction rating |
| EnvironmentSatisfaction | Work environment satisfaction |
| RelationshipSatisfaction | Relationship satisfaction rating |
| MonthlyIncome | Employee monthly salary |
| SalarySlab | Salary category |
| PercentSalaryHike | Annual salary increase percentage |
| PerformanceRating | Employee performance rating |
| OverTime | Indicates overtime status |
| WorkLifeBalance | Work-life balance rating |
| YearsAtCompany | Employee tenure |
| YearsInCurrentRole | Years in current role |
| YearsSinceLastPromotion | Years since last promotion |
| YearsWithCurrManager | Years with current manager |
| TotalWorkingYears | Total professional experience |
