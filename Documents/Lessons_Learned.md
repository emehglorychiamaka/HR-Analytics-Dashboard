# Lessons Learned

This project reinforced several important concepts in data analytics.

## Key Learnings

- Data profiling is essential before beginning any analysis.
- Small data quality issues can significantly impact dashboard accuracy.
- Data cleaning is one of the most important stages of the analytics lifecycle.
- Dashboard design should prioritize clarity over complexity.
- Effective dashboards answer business questions rather than display excessive visuals.
- Business recommendations should always be supported by data.
- Documentation improves project maintainability and reproducibility.
- GitHub serves as both a version control platform and a professional portfolio.
